## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Does Age of Empires IV have a built-in map reveal cheat?

Yes. With cheats enabled in a supported game mode, `it is known` reveals or hides the map, while `it was known` removes fog of war.

### Can I use map cheats in Ranked or Quick Match?

No. Official Age of Empires support states that cheats cannot be used in Quick Match or Ranked modes.

### What is FOW_RevealAll?

It is a SCAR scripting function documented for Age of Empires IV that reveals fog of war for all players when called from an appropriate script.

### Do cheats affect achievements and progression?

Yes. Using cheats in a game stops progression toward achievements, challenges, and masteries for that game.
